# Reply playbook

The 8 replies we'll see most, with a short answer in each language. Reply the same business day, plain text, from the same person who sent. Every reply: one point, one ask. Facts only from that prospect's check. Never argue, never "just checking in".

Rules for all languages:
- **Any opt-out wording** ("stop", "remove", "unsubscribe", "not interested", "keine Werbung", "désinscription", "cancellami", "إيقاف"), even inside an angry reply: add to the global suppression list **immediately**, stop every sequence for that business, send the one-line confirmation below (or nothing), never pitch again.
- A **GDPR access or deletion request** (UK/FR/DE/IT): forward to Varun the same day. One-month deadline.
- Prices by market: US/CA $99 / $199 / $299 · UK £79 / £159 / £239 (+VAT) · FR/DE/IT 99 € / 199 € / 299 € (HT / netto / IVA esclusa) · UAE AED 369 / 739 / 1,099 (+VAT). Links: alphaa.app/pricing, /uk, /fr, /de, /it, /ae, /ae/ar.
- Never: "free trial", "start free", "#1", "best", guaranteed rankings, invented results or customers.

| # | Reply | Move |
|---|---|---|
| 1 | "How much?" | Price + what they get + the guarantee. One link. |
| 2 | "We have an SEO agency" | Don't attack the agency. Their check is the proof: the agency's work hasn't got them named yet. Offer to run alongside. |
| 3 | "How did you get my email / address?" | Exact source and date. Offer to delete. |
| 4 | Unsubscribe / angry | Suppress. One-line confirmation. Apologise once if they're upset. |
| 5 | "Send more info" | No PDFs. Give the two fixes from their check, then one link. |
| 6 | "Can you guarantee it? / Is this real?" | Nobody controls AI answers. Here's what we can promise: the 90-day credit and the 7-day refund. The real answers are in their report. |
| 7 | "Not now" | Accept. Offer a re-check in 30-60 days with only what changed. Log consent if they say yes. |
| 8 | "Talk to my office manager / web person" | Ask for the name and address, then write to that person in a new thread citing the referral. Canada: CASL's referral exemption needs the referrer's full name in the message. DE/IT/UAE: get an explicit yes to write to them first. |
